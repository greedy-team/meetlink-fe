# MeetLink-FE

"결정 안되던 약속, 여기서 끝내세요”

모두의 시간과 위치를 고려해
가장 납득이 되는 약속을 만들어 드릴게요

사용자의 가능 시간과 출발지를 입력받아 만남 시간과 장소를 추천해주는 서비스
